# AGENTS.md

Repository rules for automation and AI agents:

- This is a Markdown-only repository. Never create or modify non-Markdown files except under `.github/`.
- Keep the existing tone and headings when editing documentation.
- Do not rewrite unrelated sections.
- Review notes belong in `reviews/<short-sha>.md`.
- Automation commits must include `[skip ci]` and use the `github-actions[bot]` identity.
